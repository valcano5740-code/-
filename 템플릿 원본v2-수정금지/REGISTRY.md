# Project Registry

## Directories

- `src/`: 소스 코드 디렉토리.
- `docs/`: 문서 디렉토리.

## Files

- `REGISTRY.md`: (현재 파일) 프로젝트 구조 정의.
- `AI_WORKFLOW_GUIDE.md`: 개발 워크플로우 가이드.
- `DEV_LOG.md`: 개발 및 이슈 로그.
- `TASK.md`: 작업 목록.
- `PLAN_TEMPLATE.md`: 구현 계획서 템플릿.
- `EVALUATION_CHECKLIST.md`: (임시) 키트 평가용 체크리스트.

## Global Rules

1.  **Register First**: 파일을 새로 만들 때는 반드시 이 파일에 먼저 등록하세요.
2.  **Conservative Separation**: 파일 분리는 신중하게. 관련 기능은 먼저 모듈화(함수/클래스)로 정의 후 필요 시 파일로 분리합니다.
3.  **Language**: 문서는 한국어/영어 혼용 가능하되, 코드는 영어를 권장합니다.
